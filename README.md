# api-client

Java client library for the [SkyMelloo/MellooEssentials Developer API](https://github.com/SkyMelloo/developer-api) - request queueing, rate-limit-aware pacing, retry/backoff, and batching where the API supports it (e.g. `presence/query`), so a mod using the API doesn't need to hand-roll that logic.

Not published yet - this repo is a placeholder.

See [DEVELOPER_API.md](https://github.com/SkyMelloo/developer-api/blob/main/DEVELOPER_API.md) for the API itself.
